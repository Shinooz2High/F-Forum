# F-FORUM — From Ideas to Real Projects 🚀
> Nền tảng tạo website và ứng dụng web bằng AI dành cho học sinh, CLB và người mới Vibe Coding với phong cách giao diện **macOS Liquid**.

---

## 🌟 Điểm Nổi Bật

- **Phong cách macOS Liquid & Cyber-Academic**:
  - Tích hợp thanh **macOS MenuBar** trên cùng (đồng hồ số, chuyển đổi Theme Sáng/Tối, tìm kiếm nhanh ⌘K).
  - Thanh **macOS Dock** nổi ở đáy màn hình với hiệu ứng phóng to (magnification) và chấm sáng trạng thái trang.
  - Các khối giao diện được bao bọc trong **macOS Window** với 3 nút điều khiển giao diện đỏ/vàng/xanh đặc trưng.
  - Tối ưu hóa **Glassmorphism** chuẩn Apple: kính mờ sâu, ánh kim hoàng gia `#EAB308` kết hợp nền tối `#07090E`.
- **Hệ thống điều hướng hoàn chỉnh**:
  - `Landing Page (/)`: Tuyên ngôn thương hiệu, quy trình 7 bước, demo thiết bị tương tác (MacBook Pro & iPhone 16 Pro).
  - `Bàn làm việc (/home)`: Ô nhập ý tưởng trung tâm, 8 tác vụ Quick Start, dự án gần đây và mẫu nổi bật.
  - `Khám phá (/explore)`: Danh mục ý tưởng sản phẩm thực tế theo nhu cầu sinh viên và CLB.
  - `Kho mẫu (/templates)`: Mẫu Website CLB, Portfolio, Phòng thi CBT trắc nghiệm, Landing page.
  - `AI Workspace Studio (/workspace)`: Mô phỏng toàn diện Omma & Arena (Chat AI, Live Preview tương tác, Code & File Tree, Diff inspector, Checks rà soát an toàn, Progress timeline và Xuất mã nguồn ZIP).
  - `Dự án của tôi (/projects)`: Quản lý dự án cá nhân, trạng thái, thẻ bài và bộ lọc.
  - `Thư viện tri thức (/knowledge)`: Source of Knowledge tuyển chọn công cụ AI, GitHub starters, Rules/Skills và UI kits đã được kiểm thử.
  - `Tác vụ nhanh (/quick-start)`: Bảng hỏi 6 bước sinh Prompt Blueprint hoàn chỉnh.
  - `Cài đặt & Maker Profile (/profile)`: Hồ sơ Maker K20, thống kê dự án và tùy chọn giao diện macOS.

## 🛠️ Hướng Dẫn Cài Đặt & Chạy

Yêu cầu máy tính đã cài đặt **Node.js 18+**.

```bash
# 1. Chuyển vào thư mục dự án
cd C:\Users\lebat\.gemini\antigravity\scratch\f-forum

# 2. Cài đặt các gói phụ thuộc (nếu chưa cài)
npm install

# 3. Khởi chạy máy chủ phát triển
npm run dev

# 4. Mở trình duyệt và truy cập:
# http://localhost:5173
```
